## 📦 설치

**Modrinth 앱** 또는 **Prism Launcher** 에서 `.mrpack` 파일을 불러오면 끝이에요.

- **Modrinth 앱**: 왼쪽 `+` → *Import from file* → `.mrpack` 선택
- **Prism Launcher**: *Add Instance* → *Import* → `.mrpack` 선택
- 메모리는 **4GB 이상**을 권장해요 (셰이더를 쓰면 6GB).

### 셰이더 켜기
[Complementary Reimagined](https://modrinth.com/shader/complementary-reimagined) 셰이더팩이 들어 있지만, 성능을 위해 **기본으로 꺼져 있어요.**
설정 → 비디오 설정 → **셰이더 팩** 에서 고르면 켜져요.

## ✅ 테스트

릴리스마다 실제 런처와 같은 방식으로 설치해서 실행해 봐요.

| 항목 | 결과 (1.0.0) |
|---|---|
| 로딩 | 크래시 없음, 타이틀 → 월드 진입 → 정상 종료 (셰이더 끔/켬 모두) |
| FPS, 셰이더 끔 | 평균 **293**, 최저 230 |
| FPS, 셰이더 켬 (Complementary Reimagined) | 평균 **117**, 최저 98 |
| 화면 | Jade, Fresh Animations, Koi Atelier 코스메틱·HUD가 셰이더를 켜도 정상 표시 |

> FPS: 1280×720, RTX 3070 Ti · i5-13400F, 수직 동기화와 프레임 제한을 끄고 시점을 한 바퀴 돌리며 10초 측정

Sodium은 Iris 1.8과 호환되는 **0.6.13으로 고정**해 뒀어요 (Sodium 0.8은 Iris 1.8과 같이 쓸 수 없어요).

## 🔧 직접 만들기

[packwiz](https://packwiz.infra.link/) 로 관리해요. 모드 목록은 `mods/*.pw.toml` 텍스트 파일이에요.

```bash
packwiz mr add <모드>          # 모드 추가 (필수 라이브러리 자동)
packwiz update --all           # 업데이트 (Sodium, Iris는 고정)
packwiz mr export              # .mrpack 만들기
```

자동 테스트:
```bash
python tools/install_mrpack.py "Koi Atelier Vanilla+-<버전>.mrpack" test-instance
# tools/pack-tester 를 빌드해서 test-instance/mods 에 넣고
PACKTEST=1 portablemc start fabric:1.21.1:0.19.5 --mc-dir test-instance -u Tester
# → 로그의 [PackTest] 줄 (FPS), test-instance/screenshots/
# 셰이더 테스트: test-instance/config/iris.properties 에 enableShaders=true
```
